# Homelab Atlas v0.12.0

Released 2026-11-18.

This fork is based on upstream Homelab Atlas v0.12.0 and removes network discovery completely. The editor is now a self-contained manual diagram tool with a read-only dashboard.

## Highlights

- **Dashboard.** Open `/dashboard` or choose **Dashboard** in the top bar for a read-only view of the browser-stored project. Linked service tiles open in a new tab.
- **Service links.** Add an optional `http://` or `https://` link to any service in the editor. Links stay out of SVG and PNG exports.
- **Browser default.** Save the current project as the starting project for this browser origin, and clear it when no longer needed. It is used only when no autosaved project exists.
- **Schema 7.** Older projects migrate on import. Discovery data is discarded; valid schema-5 links are kept, and other services gain an empty link.
- **Static server.** The Go process serves only the editor and dashboard assets plus `/healthz`. There is no project API, discovery API, or collector.

## Removed

Discovery, scanning, Docker inventory, Nmap XML import, Hawser compatibility, the separate collector profile, discovery environment variables, and their settings, tests, and documentation are gone. Existing diagrams remain editable, and their inventory, logos, connections, and manual layout are preserved.
