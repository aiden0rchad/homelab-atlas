# Homelab Atlas v0.12.1

Released 2026-11-19.

This release adds a per-project browser-tab icon and moves saved projects to schema version 8.

## Highlights

- **Custom favicon.** Choose **Diagram settings → Appearance → Upload favicon** to give a project its own browser-tab icon. PNG, JPG, WebP, SVG, and ICO files up to 2 MB are accepted and stored as a square PNG up to 128px. **Remove** restores the default Atlas mark.
- **Editor and dashboard.** The favicon is applied in both the editor and the read-only dashboard, and it travels with the project in saved JSON and the browser default.
- **Not an export asset.** Favicons are browser metadata only. SVG and PNG diagrams are unchanged.
- **Schema 8.** Imports from schema versions 1 through 7 are validated and migrated. Schema-7 projects gain an empty favicon and keep their service links.

## Upgrade notes

Atlas 0.12.1 reads projects created by earlier 0.12 releases. Older Atlas versions cannot open schema-version-8 files, so keep a JSON backup before downgrading. Browser autosave and the browser default are unchanged; the project favicon is just another project field.
